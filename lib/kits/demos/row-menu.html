row-menu

rowMenu.attach(table, opts) tap a row · Esc, a tap outside, a scroll or a resize closes it

A Tabulator grid

The GitHub cell is a link, so a tap there stays a link and raises nothing. A clipboard write needs a real tap on a secure page: in a headless shot the copy items report a failure instead of copying.

Show the TSV puts it here, and holds the menu open.

From a script

const detach = rowMenu.attach(table, {
  noun: 'kit',                                   // "Copy this kit"
  deck: { title: 'Kits' },                       // false, or omitted where record-deck is unloaded
  items: [{ label: 'Pin it', icon: 'ph-push-pin', run: ({ data }) => pin(data) }],
});
rowMenu.columnsOf(table)                         // the visible, field-bearing columns
rowMenu.tsv(cols, rows)                          // headers plus a line each, for a paste
rowMenu.open({ x, y, mark: tr, items })          // the menu alone, on any host
detach()                                         // and the row tap is a row tap again
