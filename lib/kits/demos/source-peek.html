Change the extension to .md or .js and the kind, the note and the card all follow the path, not the bytes.

From a script

SourcePeek.install()                             // one delegated listener, once per page
const a = SourcePeek.addr('me/repo', 'main', 'docs/x.md')   // 'me/repo@main:docs/x.md'
SourcePeek.seed(a, text)                         // bytes in the cache, so no fetch
SourcePeek.body('docs/x.md', text)               // { kind, text, note, truncated }
await SourcePeek.read(a)                         // { text } or { err }, fetched once
