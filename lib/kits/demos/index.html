kits / demos

web-tools

Small pages that exercise one lib/kits/ module each. The whole shelf, with what loads each kit, is the Kits tab of the app.

  • annotate Notes pinned to pieces of a page: selected text, a picked element, a dragged region, each with an anchor meant to survive a reload.
  • cm6 A CodeMirror 6 editor from a host element and an options object. No Alpine, no framework in the kit.
  • compression Brotli/Gzip + acorn + bookmarklet packer. Full UI: compression-helper.html.
  • dictate Voice input as a plain text buffer: start the engine, speak, read text back.
  • dock-split The drag handle between two panes, in either axis, with the accessibility half on the handle itself.
  • export Export a page plus the data it read()s as one zip, laid out so unzip-and-open resolves local. Optionally bakes the code in for a fully-offline page.
  • io File pick/save, blob preview, clipboard. Lazy JSZip for saveZip.
  • land Where the reader was just sent, and how they get told: the scroll, the tint, and the dwell before it fades.
  • messaging In-memory pub/sub keyed on opaque path strings; lets detached components coordinate.
  • note
  • peek What is under the pointer and what contains it; a region wrapped as a page that renders alone, proved in a frame before it is copied.
  • persistence String-path key/value over idb-keyval with structured-clone payloads.
  • read-aloud Markdown reduced to what is worth hearing, and a player that speaks it.
  • row-menu A tap on a row of a grid, and what you can then do with that row.
  • source-peek The hover card behind an exact-file GitHub link: markdown rendered, JSON shaped, everything else as source.
  • swipe-deck The house swipe format: a snap-scrolling track of slides, and the fullscreen takeover that frames it.
  • xlsx Unzip an .xlsx and walk every XML/rels part: shared strings, styles, sheet rels, comments, calc chain, reconstructed sheet data.
