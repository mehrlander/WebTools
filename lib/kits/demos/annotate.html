Five aims, one note shape

textA selection, anchored as a quote: the exact words plus the characters either side of them. It survives a re-render, and a session holding the same file re-finds it by grep.
elementA picked node. Hover outlines, tap selects, tap again takes the parent. Anchored by a css path and the text inside it.
regionA dragged rectangle in document coordinates, carrying the text of the blocks it covers, and the width it was drawn at.
pageNo anchor. The serialization already names the document and the address it was read at, so a complaint written here arrives knowing where it was taken.
sectionA part of a rendered markdown document, carrying that section's source and its line span, so what travels is markdown that can be revised and put back. It needs a declared render (kits/md-doc.js): this page is hand-written HTML, so the card hides its Section chip.

From a script

Annotate.enable({ subject: { title: 'Fund 600 notes', url: blobUrl } })
Annotate.notePage({ listen: false })      // a draft pinned to nothing, microphone off
Annotate.add({ type: 'element', selector: '.card', excerpt: 'Recordkeeping' },
              'Check which lane this sits in')
Annotate.toMarkdown()                     // the whole set, ready to paste
await Annotate.copy('json')               // annotate/1, on the clipboard
