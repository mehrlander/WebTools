The five readings

FactsThe selector, how many nodes it matches, the box, the layout, the tree position.
TreeThe subtree as an outline, attributes dropped.
HTMLThe exact outerHTML, whole on copy.
JSONThe facts as a record, with the chain.
RenderThe subtree wrapped as a page that renders alone (theme and vendor tags carried, x-* stripped), shown in a frame; Copy takes the same string. A region that renders wrong in the frame was given something by an ancestor: step up one rung.

From a script

const el = document.querySelector('.card');
Peek.facts(el).selector      // '.card', with the match count beside it
Peek.tree(el)                // the outline
Peek.wrapInfo(el)            // { html, tags, skipped, theme, nodes, bytes }
await Peek.copy('render')    // the wrapped page, on the clipboard
