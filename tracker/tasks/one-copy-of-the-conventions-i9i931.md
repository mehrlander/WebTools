# Stop storing the conventions twice

`docs/CONVENTIONS.md` and `docs/SURFACING.md` are each stored a second time at
`.claude/skills/web-tools/`, byte-identical, regenerated by `.githooks/pre-commit`
leg 1c in the same commit that touches `docs/`, and policed by a test in
`tools/test/portable-manifest.test.mjs`. The copy exists for one reason: `.claude-plugin/marketplace.json` declares the plugin's payload as
`"source": "./.claude/skills"`, so `docs/` does not travel and a script running
from an installed plugin cannot reach the originals.

The copy is buying something already free. Claude Code separately keeps a plain,
self-refreshing git checkout of this whole repository at
`~/.claude/plugins/marketplaces/web-tools/`, `docs/` included. Measured on a live
container 2026-08-31: that clone sat exactly at `origin/main`'s tip, and each
document existed **six** times on one machine (the clone's `docs/`, the clone's
skill folder, and four pinned plugin installs).

Three routes deliver the same text and disagree about freshness: the `@`-import
in this repo's own `CLAUDE.md` reads `docs/`; `inject-conventions.sh` reads the
plugin's copy, as fresh as the last `claude plugin update`; and the `/web-tools`
skill fetches `raw.githubusercontent.com` for documents sitting unread in its own
directory.

## Two stages, independently shippable

**Stage 1, low risk.** `SKILL.md`'s primary path becomes
`cat "${CLAUDE_PLUGIN_ROOT}/web-tools/$f.md"` (the idiom `markers` already uses),
demoting the existing `curl` to the first fallback. One Markdown file, no
deletions, three delivery routes become two.

**Stage 2, needs the decision above.** `inject-conventions.sh` resolves its
source through a chain: the marketplace clone's `docs/`, then the script's own
directory (still populated on older pinned installs, which is what makes the
transition safe), then a named failure printed rather than today's silent
`exit 0`. Then delete both copies and the byte-parity test that exists only to
police them.

## What does not change

Who receives the conventions, which repositories opt in (injection is per repo
through the dispatcher, not per plugin install), the payload's byte ceiling and
its drop order, skills staying advertised rather than injected, and every other
document staying uninjected.

## The risk, and its containment

Stage 2 trades a hand-maintained copy for a dependency on a Claude Code internal
path. The fallback chain covers a moved or absent clone, and
`tools/test/conventions-delivery.test.mjs` already executes the injector as a
subprocess, so a path change fails CI rather than surfacing in a session days
later. Unchanged either way: a test can prove the script emitted the right bytes,
never that the session received them, since truncation happens after a successful
exit.

The measured case for it is `docs/delivery.json` and its
[Conventions Delivery](https://mehrlander.github.io/web-tools/pages/delivery.html)
page (#564): the current snapshot is this reading, and the planned one is this
task's end state. Its evidence corrects one premise this task was filed on. The
copy is **not** hand-maintained, so the cost is not a forgotten `cp`; it is lag
between commits, caused by pinning. Across 47 recorded sessions carrying both an
`@`-import and an injection receipt for `SURFACING.md`, **12 delivered different
versions by the two routes**, and the version the injector kept delivering
(`dc188a49`, `SURFACING.md` as of 2026-08-27) was still arriving on 2026-09-01.
Sharper still: one session's payload came to 28,026 bytes against a 28,000-byte
ceiling and was cut, while the gap between the pinned copy and the tip was 1,210
bytes, far larger than the 26-byte overrun.

Reviewer-facing writeup, with the current-state code quoted verbatim:
[One Copy of the Conventions](https://claude.ai/code/artifact/c93ed5f0-e2d1-49dd-871d-b42c48c4f4b5).

## Done when

Stage 1 is in and the skill no longer fetches on its normal path. If stage 2 is
taken: `.claude/skills/web-tools/` holds only `SKILL.md`, the byte-parity test is
gone, `docs/PORTABLE.md`'s no-fetch rationale is rewritten to match, and
`conventions-delivery.test.mjs` covers the fallback chain including the named
failure.
