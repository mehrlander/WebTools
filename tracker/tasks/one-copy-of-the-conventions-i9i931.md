# Stop storing the conventions twice

`docs/CONVENTIONS.md` and `docs/SURFACING.md` are stored a second time at
`.claude/skills/web-tools/`, byte-identical, regenerated by `.githooks/pre-commit`
leg 1c and policed by `tools/test/portable-manifest.test.mjs`. The copy exists
because `.claude-plugin/marketplace.json` declares the payload as
`"source": "./.claude/skills"`, so `docs/` does not travel.

It buys something already free. Claude Code keeps a self-refreshing checkout of
the whole repository at `~/.claude/plugins/marketplaces/web-tools/`, `docs/`
included. Measured 2026-08-31: that clone sat at `origin/main`'s tip, and each
document existed **six** times on one machine.

Three routes deliver the same text and disagree about freshness: the `@`-import
reads `docs/`; `inject-conventions.sh` reads the plugin's copy, as fresh as the
last `claude plugin update`; and `/web-tools` fetches raw.githubusercontent.com
for documents sitting unread in its own directory.

## Two stages, independently shippable

**Stage 1, low risk.** `SKILL.md`'s primary path becomes
`cat "${CLAUDE_PLUGIN_ROOT}/web-tools/$f.md"` (the idiom `markers` already uses),
demoting `curl` to first fallback. One file, no deletions, three routes to two.

**Stage 2, needs the decision above.** `inject-conventions.sh` resolves through a
chain: the marketplace clone's `docs/`, then the script's own directory (still
populated on older pinned installs, which is what makes the transition safe),
then a named failure rather than today's silent `exit 0`. Then delete both copies
and the byte-parity test policing them.

## The cost, measured

The premise this was filed on is wrong and the evidence corrects it: the copy is
**not** hand-maintained, so the cost is not a forgotten `cp` but lag from
pinning. Across 47 sessions carrying both an `@`-import and an injection receipt
for `SURFACING.md`, **12 delivered different versions by the two routes**, and
the version the injector kept sending (`dc188a49`, as of 2026-08-27) still
arrived on 2026-09-01. Sharper: one payload hit 28,026 bytes against a 28,000
ceiling and was cut, while the pinned-copy gap was 1,210 bytes, far larger than
the 26-byte overrun. Source: `docs/delivery.json` and its
[Conventions Delivery](https://mehrlander.github.io/web-tools/pages/delivery.html)
page (#564).

## Risk
Stage 2 trades a regenerated copy for a dependency on a Claude Code internal
path. The fallback chain covers a moved clone, and
`tools/test/conventions-delivery.test.mjs` already runs the injector as a
subprocess, so a path change fails CI rather than surfacing days later. Unchanged
either way: a test can prove the script emitted the right bytes, never that the
session received them, since truncation happens after a successful exit.

Unchanged by either stage: who receives the conventions, which repositories opt
in, the payload ceiling and drop order, and every other document staying
uninjected.

## Done when
Stage 1 is in and the skill no longer fetches on its normal path. If stage 2 is
taken: `.claude/skills/web-tools/` holds only `SKILL.md`, the byte-parity test is
gone, `docs/PORTABLE.md`'s no-fetch rationale is rewritten, and
`conventions-delivery.test.mjs` covers the chain including the named failure.
